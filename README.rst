=========================
collective.js.tooltipster
=========================
   
Plone integration of Tooltipster jQuery plugin (https://calebjacob.github.io/tooltipster/)

Version 4.2.6

Themes
****** 

The default profile also installs the theme stylesheets (one bundle each):

- tooltipster-borderless
- tooltipster-light
- tooltipster-noir
- tooltipster-punk
- tooltipster-shadow
